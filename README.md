# Zeladoria — GitHub Pages

- `index.html` — Dashboard online
- `cadastro.html` — Cadastro de Ordens de Serviço

A aplicação consulta e grava diretamente no Supabase pelo REST API e não depende de Excel.

## Publicar

GitHub → repositório → **Settings → Pages → Deploy from a branch → main → /(root)**.

Se quiser usar a logo, coloque `logo zeladoria.png` na raiz do repositório.
